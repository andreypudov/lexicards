#+TITLE: LexiCards
#+SUBTITLE: Ambient vocabulary learning for macOS
#+OPTIONS: toc:nil

[[./Assets/Icon.png]]

LexiCards keeps vocabulary in view while you work. It runs in the menu bar and shows a small floating card that rotates through words and their translations, with short recall sessions to test what you remember.

* Features

- *Floating card:* stays above other windows, across Spaces and full-screen apps.
- *Automatic rotation:* shows a random word every eight seconds by default.
- *Recall sessions:* tests you on up to ten words, on a schedule or on demand.
- *Pronunciation:* speaks words with the system voices, with automatic language detection.
- *Your own vocabulary:* use the built-in lists or add any two-column CSV file.
- *Stays out of the way:* has no Dock icon, and fades when the pointer rests on the card.

* Requirements

- macOS 13.5 or later
- Xcode 26 or later, to build from source

* Installation

** Homebrew (recommended)

#+begin_src sh
brew tap andreypudov/lexicards
brew trust andreypudov/lexicards
brew install --cask lexicards
#+end_src

To upgrade later, run =brew update && brew upgrade --cask lexicards=.

** Prebuilt release

Download the latest =LexiCards-x.y.zip= from the [[https://github.com/AndreyPudov/lexicards/releases][Releases page]], unzip it, and move =LexiCards.app= to =/Applications=.

** Build from source

#+begin_src sh
git clone https://github.com/AndreyPudov/lexicards.git
cd lexicards
make install
#+end_src

** First launch of a downloaded copy

Releases are self-signed and not notarized, so macOS may block the first launch of a copy installed with Homebrew or downloaded from the Releases page. Allow it in *System Settings > Privacy & Security*, or clear the quarantine flag:

#+begin_src sh
xattr -dr com.apple.quarantine /Applications/LexiCards.app
#+end_src

Copies you build yourself are not affected.

* Getting started

1. Launch LexiCards. A card appears near the lower-right corner of the screen, showing a built-in vocabulary.
2. Drag the card to where you want it, or drag either side to change its width.
3. Open the LexiCards menu in the menu bar and choose *Vocabulary* to pick another list or add your own.
4. Choose *Recall Now* to try a session.

To use your own words, create a UTF-8 CSV file with the original in the first column and the translation in the second, without a header row:

#+begin_example
猫,cat
犬,dog
水,water
#+end_example
