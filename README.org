* Overview

*LexiCards* is a lightweight, modern macOS application designed to support continuous vocabulary learning through subtle, high‑frequency exposure. It lives in the macOS menu bar and displays a small floating card with a rotating sequence of words and their translations without interrupting your workflow.

*LexiCards* is intentionally minimalistic: no regular windows, no clutter, no distractions — just clean, ambient reinforcement of the vocabulary you want to learn.

* Features

- Native macOS menu‑bar integration
- Automatic cycling of vocabulary pairs
- Floating word card in the lower-right corner
- Card visible across Spaces and full-screen apps
- Card visibility toggle in the menu bar
- Support for user‑provided vocabulary files
- Fast, lightweight Swift implementation

*LexiCards* is ideal for language learners who prefer a passive, always‑visible learning tool that blends seamlessly into their daily computing environment.

* Loading Vocabulary

*LexiCards* reads vocabulary from a simple CSV file containing two columns:

#+begin_example
Original,Translation
猫,cat
犬,dog
水,water
空,sky
#+end_example

** Format requirements:

- Two columns: Original and Translation
- Comma‑separated (,), UTF‑8 encoded
- Header row is optional
- Each row represents one vocabulary pair

Once loaded, *LexiCards* cycles through the entries at a regular interval, displaying each pair in the floating card. Use *Show Card* in the menu bar to hide or show it.

* Installation & Usage

1. Launch *LexiCards* on macOS (macOS 12+ recommended).
2. The *LexiCards* control will appear in the menu bar and a card will appear in the lower-right corner.
3. Load your CSV vocabulary file through the app’s menu.
4. Words will begin cycling automatically.

*LexiCards* runs entirely from the menu bar and can be quit at any time from its dropdown menu.
